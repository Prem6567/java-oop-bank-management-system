🏦 Bank Management System in Java

📌 Project Overview

The Bank Management System is a console-based Java application developed using Object-Oriented Programming (OOP) principles. It allows users to manage basic banking operations through an interactive menu-driven interface.

This project demonstrates Java programming concepts, encapsulation, constructors, object creation, and input validation.

🎯 Project Objectives

- Understand Object-Oriented Programming in Java.
- Implement encapsulation using private data members.
- Manage bank account information using classes and objects.
- Perform basic banking operations.
- Handle invalid user inputs and transactions.

✨ Features

- Account Creation: Enter the account holder's name and account number.
- Account Details: Display account information.
- Deposit Money: Add money to the account balance.
- Withdraw Money: Withdraw money if sufficient funds are available.
- Balance Inquiry: Check the current account balance.
- Input Validation: Handle invalid amounts and menu choices.
- Interactive Menu: Perform multiple operations until the user exits.

🛠️ Technologies Used

- Programming Language: Java
- Core Concepts: OOP, Encapsulation, Classes, Objects, Constructors, Methods
- Input Handling: Scanner Class
- Development Environment: Any Java-compatible IDE or compiler

💡 OOP Concepts Demonstrated

1. Encapsulation

Account information and balance are stored in private fields and accessed through public methods.

2. Classes and Objects

The "BankAccount" class represents a bank account, and its object manages account information and transactions.

3. Constructor

The constructor initializes the account holder's name, account number, and initial balance.

4. Methods

Separate methods perform deposits, withdrawals, balance inquiries, and account detail displays.

5. Input Validation

The application validates user inputs and prevents negative deposits, invalid withdrawals, and withdrawals exceeding the available balance.

⚠️ Limitations

This project is designed for educational purposes. It stores account information only during program execution and does not provide persistent storage, secure authentication, or production-grade financial transaction processing.

Do not use this application to manage real bank accounts or money.
